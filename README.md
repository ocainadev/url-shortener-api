# URL Shortener API

A RESTful API for generating shortened URLs and redirecting users to the original links.
This project was developed to practice backend development using **ASP.NET Core**, **Entity Framework Core**, and **SQL Server**, focusing on clean architecture and REST API design.

---

## Features

- Generate shortened URLs from long links
- Redirect users to the original URL using a short code
- Store URLs in a relational database
- RESTful API design
- Clean and organized backend structure
